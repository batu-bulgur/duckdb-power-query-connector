# 0.6.0 — GUI text shaping

## Added

- SQL mappings for Text.Start, Text.End, Text.Replace, Text.Split and Text.Combine.
- Ordered UTF-16 text-list transport, native M type-error reconstruction and
  optimized-expression extraction for fixed-separator column merges.

## Fixed

- Emit portable Python-style SQL lambdas in the shared UTF-16/equality helpers.
  The installed ODBC engine v2.0.0 rejects single-arrow lambdas by default;
  the new syntax also supports CI's pinned ODBC 1.4.4.0.

## Query folding

- Text calculations retain UTF-16 units across nested list and text expressions.
- Dynamic arguments and native M type-error restoration share the SQL error channel.
- GUI TransformColumns, ReplaceValue and ordinary CombineColumns paths retain
  calculations in SQL, including subsequent text-type annotations.
- Group, distinct and ordered index chains preserve encoded text. The new
  million-row prefix filter has a one-row transfer budget.

## Known limitations

- The pinned SDK does not dispatch field-list constructors with row-dependent
  separators or list element-access expressions to OnAddColumns. A standalone
  sentinel-handler reference and correct-result negative controls prove this
  boundary. Dynamic separators on represented split/constant lists do fold.
- GUI SplitColumn with its generated splitter remains a correct-result negative.
  The ordinary GUI CombineColumns delimiter path is separately positive.
- Existing native TIMESTAMPTZ/UTC-range and untranslated-expression boundaries
  remain; complete M-language or complete GUI split-family parity is not claimed.
- SDK/ODBC verification does not establish Excel or Power BI Desktop GUI integration.
- Scope and reproducers are in the
  [text-shaping report](https://github.com/batu-bulgur/duckdb-power-query-connector/blob/fork-v0.6.0/docs/text-shaping-parity.md).

## Validation

- Complete local verification passed with SDK 2.155.2 and the installed ODBC
  engine v2.0.0: 188 distinct strict SQL/ODBC cases, 42 functional tests,
  119 source-free M references, seven negative folding controls, four native
  failure reproducers and 16 runner rejection controls.
- The new group adds 28,335 direct M value/error comparisons and 26 strict
  cases; total paired scalar coverage is 217,707 comparisons. The million-row
  prefix filter transferred one ODBC row. All 20 packaged resources match source
  and the package loads in the SDK.
- Hosted verification uses the separately pinned ODBC 1.4.4.0. Local results
  do not stand in for that required PR/main check.
