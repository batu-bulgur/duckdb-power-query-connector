# 0.3.0 — İlk kişisel fork sürümü

Bu sürüm, MotherDuck upstream `v0.2.0` tabanı üzerine eklenen doğrulanmış
iyileştirmeleri bir araya getirir. Kişisel fork tag'i `fork-v0.3.0`'dır.
Aktif scalar parite çalışmasının henüz birleştirilmemiş fonksiyonları bu sürüme dahil değildir.

## Eklenenler

- `List.StandardDeviation`: doğrudan sayısal kolonlarda global ve gruplu örneklem
  standart sapması SQL'e aktarılır. M ile uyumlu olarak tek geçerli değer için
  sonuç sıfır, boş veya tümü NULL girdi için NULL olur.
- `Text.EndsWith`: varsayılan comparer ile native DuckDB `RIGHT`/`LENGTH`
  eşlemesi. Literal `%`, `_`, kesme işareti, ters bölü, Türkçe karakter ve emoji
  senaryoları; gruplama ve LIMIT/OFFSET bileşimleri regresyonlarla korunur.
- İki fonksiyon tek visitor kaydını paylaşır; scalar suffix desteği aggregate
  standart sapma desteğinin yerini almaz.
- Power Query SDK ile headless doğrulama, sentetik fixture'lar, sonuç/SQL/ODBC
  satır aktarımı kontrolleri ve başarısız sonucu yakalayan test runner.
- SemVer, sürüme özel release notları, paket kaynak kontrolü ve yeşil main
  build'inin aynı artifact'inden otomatik kişisel release yayımlama.

## Düzeltilenler

- LIMIT/OFFSET capability bildirimi: sort → skip → take zincirinin gereksiz
  tam tablo aktarımı yerine sayfalama SQL'i üretmesi sağlandı.
- Metin literal karşılaştırmalarında sorunlu string parametre bağlama yolu
  yerine mevcut generator'ın literal quoting davranışı kullanılıyor.
- VARCHAR/NVARCHAR tip bilgisi ve eklemeli implicit conversion sayesinde
  Unicode eşitlik, kolonun etrafına cast eklenmeden fold ediliyor.
- Windows CI ODBC asset URL'si, yerel klasör yolu yerine doğru dosya adını
  ve toolchain'deki sabit sürümü kullanıyor.

## Query folding

| İşlem | Bu sürümdeki kapsam / kanıt |
| --- | --- |
| Sayısal/tarih/metin filtreleri, projection | Doğru sonuç + SQL + satır bütçesi |
| SUM, COUNT, DISTINCT ve gruplama | Sentetik regresyonlar |
| LIMIT ve LIMIT/OFFSET | Sıfır skip, tablo sonunu aşma ve standalone OFFSET dahil |
| Contains / StartsWith | Literal quote ve wildcard kaçışları dahil |
| Unicode eşitlik | Türkçe I ayrımları ve emoji; milyon satırdan bir satır aktarımı |
| EndsWith | Varsayılan comparer; milyon satırlık seçilimde en fazla üç satır aktarımı |
| StandardDeviation | Doğrudan sayısal kolon; örneklem semantiği ve milyon satırda tek aggregate satırı |

Buradaki folding beyanı, beklenen M sonucuyla beraber üretilen SQL ve gerçek
ODBC aktarım sayısının doğrulandığı kapsamı anlatır; her overload için genel parite iddiası değildir.

## Sınırlar

- `Text.EndsWith` için açık comparer overload'ları M tarafında kalır; ordinal
  olmayan karşılaştırma semantiği sessizce değiştirilmez.
- `List.StandardDeviation` eşlemesi doğrudan sayısal kolon aggregate'leri içindir.
- `Table.AddIndexColumn` ve `Value.NativeQuery` sonrasındaki dönüşümlerin folding'i
  desteklenmiş sayılmaz; negatif kontroller bunları reddeder.
- `AstVisitor.Functions`/`Invocation` şeması SDK 2.155.2 üzerinde ölçülmüştür;
  diğer Mashup sürümlerinde ayrıca doğrulanmalıdır.
- Excel veya Power BI Desktop GUI entegrasyonu bu release'in test kanıtı değildir.
  `.mez` için belgelenmiş Power BI kurulum ve mevcut kurum trust politikası izlenmelidir.
- ADBC geçişi, yüklü sürücü/DSN değişikliği ve üretim verisi testi yoktur.

## Doğrulama

- Sonuç karşılaştırmaları, SQL kalıpları, tek ODBC sorgusu ve satır bütçeleri
  birlikte kontrol edilir. PQTest'in yalnızca sıfır exit code vermesi yeterli değildir.
- Taban paket, SDK 2.155.2 ve hosted ODBC 1.4.4.0 ile PR #1'in CI koşusunda geçti.
- Birleşik EndsWith/StandardDeviation uygulaması yerelde SDK 2.155.2 / ODBC motoru
  1.5.4 ile 6 fonksiyonel test, 40 folding testi, 10 runner reddetme kontrolü
  ve 2 beklenen negatif kontrolü geçti.
- Bu sürüm yalnızca kendi commit'inin hosted Windows main build'i başarılı
  olduktan sonra yayımlanır. Kesin commit, build bağlantısı, SDK/sürücü sürümleri
  ve `.mez` SHA-256 değeri release'e eklenen `release-manifest.json` içindedir.
- `.mez`, MSBuild artifact'inden alınır; release sırasında yeniden build edilmez.
  Paketteki 12 allowlist kaynağın hash'i sürümün kaynak dosyalarıyla eşleştirilir.
