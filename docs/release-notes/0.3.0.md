# 0.3.0 — First personal fork release

This release collects verified improvements on top of MotherDuck upstream
`v0.2.0`. The personal fork tag is `fork-v0.3.0`. Unmerged functions from the
ongoing scalar parity research are not included.

## Added

- `List.StandardDeviation`: global and grouped sample standard deviation over
  direct numeric columns folds to SQL. Following M semantics, a single valid
  value returns zero; empty or all-NULL input returns NULL.
- `Text.EndsWith`: native DuckDB `RIGHT`/`LENGTH` mapping for the default comparer.
  Regressions cover literal `%`, `_`, apostrophes, backslashes, Turkish characters,
  emoji, and composition with grouping and LIMIT/OFFSET.
- Both functions share one visitor registration, preserving aggregate standard
  deviation support alongside scalar suffix support.
- Headless Power Query SDK validation with synthetic fixtures, correct-result,
  SQL and ODBC-row checks, and a test runner that rejects failed results.
- SemVer, version-specific release notes, package/source verification and
  automatic personal-fork releases using the exact successful main build artifact.

## Fixed

- LIMIT/OFFSET capability declarations produce pagination SQL for sort → skip →
  take, avoiding an unnecessary full-table transfer.
- Text literal comparisons use the existing generator's literal quoting instead
  of the problematic string parameter binding path.
- VARCHAR/NVARCHAR type information and additive implicit conversion allow
  Unicode equality to fold without adding a cast around the column.
- The Windows CI ODBC asset URL uses the correct filename and pinned toolchain
  version instead of a local directory path.

## Query folding

| Operation | Scope / evidence in this release |
| --- | --- |
| Numeric/date/text filters and projection | Correct results, SQL and row budgets |
| SUM, COUNT, DISTINCT and grouping | Synthetic regressions |
| LIMIT and LIMIT/OFFSET | Includes zero skip, skipping past the end and standalone OFFSET |
| Contains / StartsWith | Includes literal quotes and wildcard escapes |
| Unicode equality | Turkish I distinctions and emoji; one row transferred from a million-row fixture |
| EndsWith | Default comparer; at most three rows transferred from a million-row selection fixture |
| StandardDeviation | Direct numeric column; sample semantics and one aggregate row from a million-row fixture |

These claims cover operations whose expected M results, generated SQL and actual
ODBC transfer counts were verified. They do not imply parity for every overload.

## Known limitations

- Explicit comparer overloads of `Text.EndsWith` remain in M; non-ordinal
  comparison semantics are not silently changed.
- The `List.StandardDeviation` mapping covers direct numeric column aggregates.
- `Table.AddIndexColumn` and transformations after `Value.NativeQuery` are not
  claimed to fold; negative controls reject those cases.
- The `AstVisitor.Functions`/`Invocation` schema was measured with SDK 2.155.2;
  other Mashup versions require separate validation.
- This release does not establish Excel or Power BI Desktop GUI integration.
  Follow the documented Power BI installation steps and existing organizational
  trust policy for `.mez` files.
- No ADBC migration, installed driver/DSN changes or production-data tests are
  included.

## Validation

- Result comparisons, SQL patterns, a single ODBC query and row budgets are
  checked together. A zero PQTest exit code alone is insufficient.
- The foundation package passed PR #1 CI with SDK 2.155.2 and hosted ODBC 1.4.4.0.
- The combined EndsWith/StandardDeviation implementation passed 6 functional
  tests, 40 folding tests, 10 runner rejection checks and 2 expected negative
  controls locally with SDK 2.155.2 / ODBC engine 1.5.4.
- Publication follows the successful hosted Windows main build for the exact
  release commit. The attached `release-manifest.json` records that commit, build
  URL, SDK/driver versions and `.mez` SHA-256.
- The `.mez` comes from the MSBuild artifact and is not rebuilt during release.
  Hashes of all 12 allowlisted package resources are matched against the versioned
  source files.
