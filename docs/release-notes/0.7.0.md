# 0.7.0 — Column profile aggregate folding

## Added

- Fold supported native-column `Table.Profile` aggregate groups into DuckDB,
  including row/null/distinct counts and guarded custom numeric counters.
- Preserve M datetime averages at 100 ns precision with exact integer tick
  arithmetic and the existing temporal decoder.

## Fixed

- Avoid transferring the entire native rowset for supported column profiling
  requests initiated by Power Query's result and details panes.
- Preserve NaN distinctness/extrema, UTF-16 text extrema, negative fractional
  parity and nested error-count semantics while compiling these groups.

## Query folding

- Ten new strict SQL/ODBC cases cover full, sampled and filtered profiles,
  native edge values, custom counts, Int64 precision and datetime averages.
  Each profile returns one aggregate data row. Timestamp classification uses
  its separately bounded catalog request.
- Retain the complete scalar, date, text-list and relational folding behavior
  shipped in 0.6.1. The public DuckDB.Contents signature and runtime baseline
  remain unchanged: SDK 2.155.2, DuckDB 2.0.0, ODBC 2.0.0.1.
- This is a minor version because it adds measured folding capabilities.

## Known limitations

- Unsupported additional profile aggregates, encoded input columns, unguarded
  numeric classifiers, DECIMAL/NUMERIC columns, TIME averages and native TIMESTAMPTZ retain local M
  evaluation. Empty profiles may still issue separate scalar-default queries.
- Entire-dataset profiling can still scan the source inside DuckDB; this change
  reduces transferred rows and local materialization, not the requested scope.
- Power BI Desktop/Excel host integration and final editor timing require
  separate validation. New Power Query experience and security settings are
  unchanged. Packages are delivered through GitHub Releases.
- See the [profiling contract](https://github.com/batu-bulgur/duckdb-power-query-connector/blob/fork-v0.7.0/docs/preview-profiling.md)
  for the trigger, representation and boundaries.

## Validation

- The complete suite contains 199 strict SQL/ODBC folding cases, 46 functional
  tests, 121 source-free M references, seven negative controls, four native
  failure reproducers and 16 runner rejection controls.
- The new independent temporal oracle checks 18 averages across years 1, 2026
  and 9999, including fractional 100 ns results and truncation boundaries.
- Package/source integrity and SDK loading cover all 20 allowlisted resources.
- Local verification and hosted PR/main checks are required before publication;
  per-build evidence and the published artifact receipt are linked from the PR.
