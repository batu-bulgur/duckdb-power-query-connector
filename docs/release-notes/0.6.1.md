# 0.6.1 — DuckDB 2 runtime baseline

## Added

- Versioned primary runtime: DuckDB engine 2.0.0 through Windows AMD64 ODBC 2.0.0.1,
  with SDK 2.155.2. Connector and driver version numbers are independent.
- A pinned SHA-256 check for the official CI driver download.

## Fixed

- Align the hosted runtime with the installed DuckDB 2 driver used locally.
  The local DLL is byte-for-byte identical to the official 2.0.0.1 release DLL.

## Query folding

- Carry the complete scalar, date, text-list and relational folding suite onto
  the DuckDB 2 baseline, including GUI transformations and ordered index chains.
- Retain Python-style SQL lambdas, UTF-16 units, exact numeric/date semantics
  and the scalar overlap-reduction state introduced in 0.6.0.
- Patch classification preserves the public DuckDB.Contents, authentication,
  navigation/schema and supported M result contracts.

## Known limitations

- Existing SDK expression-dispatch, opaque-comparer and native timezone/UTC-range
  boundaries remain. A newer SQL engine does not establish SDK expression access.
- Excel and Power BI Desktop GUI integration require separate host validation.
- Runtime identity and follow-up SQL simplification criteria are in the
  [runtime contract](https://github.com/batu-bulgur/duckdb-power-query-connector/blob/fork-v0.6.1/docs/duckdb-2-runtime.md).

## Validation

- The required complete suite contains 189 strict SQL/ODBC folding cases,
  42 functional tests, 120 source-free M references, seven negative controls,
  four native failure reproducers and 16 runner rejection controls.
- Local and hosted runs must use the 2.0 runtime before delivery. Paired scalar
  coverage remains 217,707 direct M value/error comparisons.
- Package/source integrity and SDK loading cover all 20 allowlisted resources.
- The official driver ZIP SHA-256 is
  `0319071a1d1f5eab93ae01a69d9aa7d39c772ebcf3ff4e856fc5ad654460e63e`.
  Per-build and published-package receipts are linked from the feature PR.
